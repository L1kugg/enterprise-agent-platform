## 1. 总体目标

在现有基础上补齐白皮书第 5 章和 UI 改造文档要求的完整产品能力，实现：

1. 智能体配置可真实驱动模型、提示词、记忆、知识库、工具、工作流、安全防护和发布渠道。
2. 工作流支持可视化编排、导入导出、试运行、上线/下线和真实执行。
3. 工具支持结构化配置、测试、执行和安全约束。
4. 知识库配置与现有文档解析/向量检索体系打通。
5. 安全防护在会话和智能体调用前真实生效。
6. 模型服务配置可参与真实模型路由与调用。
7. 系统管理补齐用户、角色、资源授权和数据库连接测试。
8. 前端提供统一、可操作、状态清晰的企业级工作台。

## 2. 非目标

以下内容本需求不包含：

- 更换前端框架、路由方案、UI 组件库或后端主要框架。
- 绕过现有 RBAC、租户隔离、审计和安全机制另建权限体系。
- 使用 mock 数据冒充真实功能。
- 直接在前端执行不可信代码或 SQL。
- 在日志、错误提示、前端状态中暴露明文密钥、内部堆栈或敏感网络信息。

## 3. 角色与权限

| 角色 | 使用场景 | 权限要求 |
| --- | --- | --- |
| 普通用户 | 使用智能体、调试智能体、查看已授权资源 | 仅能访问被授权的智能体、知识库、工具、工作流 |
| 智能体开发者 | 编排智能体、绑定资源、调试、发布 | 可创建/修改草稿，发布需具备发布权限 |
| 工作流开发者 | 编排和管理工作流 | 可创建、修改、试运行、上线/下线已授权工作流 |
| 平台管理员 | 管理模型、安全策略、数据库、用户、角色 | 具备平台配置和系统管理权限 |
| 系统管理员 | 用户/角色/授权/密钥治理 | 高危操作必须二次确认并写审计日志 |

要求：

- 所有权限必须由后端强制校验，前端隐藏按钮不能作为安全边界。
- 所有列表、详情、执行、测试接口必须支持租户隔离。
- 资源级授权不能破坏现有角色权限体系。
- 敏感操作写入现有审计日志。

# R1 智能体运行时闭环

## R1.1 背景

当前智能体资源可以保存以下配置：

- 名称、简介
- 系统提示词
- `modelId`
- 模型参数，例如 `temperature`
- 开场白、引导问题
- `workflowIds`
- 工具绑定
- `knowledgeBaseIds`
- `safetyGuardIds`
- `memoryTurns`
- 发布渠道

但这些配置尚未参与真实会话执行。

## R1.2 功能需求

### FR-R1-01 按智能体发起会话

后端：

- 新增或扩展聊天接口，支持 `agentId`。
- 加载当前租户下可见、已启用的智能体配置。
- 普通聊天接口与智能体聊天接口必须共用同一套安全、租户、审计、限流机制。
- 请求未发布智能体时：
  - 具备调试权限的用户可调试。
  - 普通用户返回明确无权限错误。

前端：

- 对话工作台增加智能体选择器。
- 显示智能体名称、状态、简介。
- 只展示用户有权限使用的智能体。
- 选中智能体后，会话上下文绑定该智能体。

验收标准：

- [ ] 选择智能体后，请求携带或关联 `agentId`。
- [ ] 后端根据 `agentId` 加载配置。
- [ ] 未授权智能体返回 403 或业务权限错误。
- [ ] 聊天记录可追溯到智能体 ID。

### FR-R1-02 提示词生效

后端：

- 将智能体 `prompt` 注入模型系统消息。
- 与现有平台默认提示词、RAG 提示词、安全提示词的合并策略必须明确。
- 禁止用户提示词覆盖平台级安全指令。

前端：

- 智能体工作台提供提示词必填校验。
- 显示提示词长度和基本风险提示。
- 保存空提示词时阻止提交。

验收标准：

- [ ] 同一问题在配置不同提示词时，模型行为符合配置。
- [ ] 系统提示词不会泄漏给普通用户。
- [ ] 提示词变更后新会话生效，历史会话不重写。

### FR-R1-03 模型与参数生效

后端：

- 按 `modelId` 从模型服务配置加载模型。
- 将 `temperature` 等模型参数传入真实模型调用。
- 校验参数范围。
- 模型不可用时返回明确错误，并可回退到项目已有模型档位或直接失败，策略需可配置。
- 记录模型调用耗时、token、费用和 trace。

前端：

- 模型选择列表来自 `/platform/model-services`。
- 展示模型状态。
- 参数控件限制合法范围。
- 聊天调试区展示实际使用的模型摘要。

验收标准：

- [ ] 智能体选择不同模型时，后端调用对应模型配置。
- [ ] 非法参数被拒绝或归一化，策略明确。
- [ ] 模型调用失败时前端有可理解错误。

### FR-R1-04 开场白与引导问题生效

后端：

- 提供智能体开场白和引导问题。
- 或在智能体详情接口中返回，由前端初始化展示。

前端：

- 新会话选择智能体后展示开场白。
- 引导问题以可点击问题列表展示。
- 点击后填入输入框或直接发送。
- 无开场白时不显示空白模块。

验收标准：

- [ ] 配置开场白后新会话自动展示。
- [ ] 配置引导问题后可点击触发。
- [ ] 修改配置后新会话生效。

### FR-R1-05 短期记忆轮数生效

后端：

- 按 `memoryTurns` 裁剪注入模型的历史消息。
- 与现有长期记忆、RAG、会话状态机制兼容。
- 会话保存不因记忆裁剪而丢失完整历史。

前端：

- 对话设置提供轮数说明。
- 调试区可展示实际注入轮数摘要，不暴露完整内部上下文。

验收标准：

- [ ] 不同 `memoryTurns` 生成不同历史注入。
- [ ] 数据库仍保留完整会话历史。

### FR-R1-06 资源绑定运行时生效

后端需按以下顺序或项目最终确定顺序执行：

1. 安全防护检查
2. 记忆构建
3. 知识库召回
4. 工具或工作流决策
5. 模型调用
6. 输出与观测记录

要求：

- 加载智能体绑定的知识库、工具、工作流、安全防护。
- 只加载已启用/已上线且当前用户有权限的资源。
- 绑定资源不存在或不可用时返回明确配置错误。
- 执行过程中记录资源调用结果，但默认不向普通用户暴露完整原始输入输出。

验收标准：

- [ ] 智能体绑定知识库后只在绑定范围内召回。
- [ ] 绑定工具后可按模型决策调用。
- [ ] 绑定安全防护后可拦截。
- [ ] 绑定工作流后可进入工作流执行。
- [ ] 无权限资源不会被加载。

## R1.3 数据模型建议

在现有 `platform_asset` 之上增加关系表，避免继续依赖纯 JSON：

- `binding_order`
- `execution_confirm`
- `created_at`
- `updated_at`

需保留迁移方案，将既有 JSON 绑定数据迁入关系表。

# R2 智能体调试与观测

## R2.1 智能体调试

后端：

- 提供调试接口，例如 `POST /platform/agents/{id}/debug`。
- 支持输入消息、测试变量、调试选项。
- 返回：
  - 最终回答
  - 状态
  - 模型摘要
  - 知识召回摘要
  - 工具调用摘要
  - 工作流执行摘要
  - 安全防护结果
  - 错误信息
- 支持 JSON 或 SSE。
- 调试记录入库。
- 原始 thought、actionInput、工具响应默认不返回给普通用户。
- 管理员可查看脱敏后的详细调试数据。

前端：

- 智能体工作台右栏实现真实调试对话。
- 区分“保存配置”和“运行调试”。
- 支持加载中、成功、失败、停止。
- 展示分段过程摘要。
- 支持折叠查看详细调试信息。
- 未保存修改时提示先保存或明确以草稿调试。

验收标准：

- [ ] 调试调用真实后端接口。
- [ ] 不模拟成功。
- [ ] 调试过程可看到各配置是否生效。
- [ ] 错误可定位到模型、知识库、工具或工作流。

## R2.2 智能体详情与看板

后端：

- 提供智能体详情聚合接口：
  - 基本信息
  - 配置摘要
  - 最近调用
  - 成功率
  - 平均耗时
  - token 用量
  - 费用
  - 常见错误
- 数据必须来自真实调用日志。

前端：

- 智能体详情页分区展示：
  - 概览
  - 配置
  - 调用日志
  - 调试
  - 分析看板

验收标准：

- [ ] 无调用数据时显示空状态。
- [ ] 不展示虚构数字。
- [ ] 日志可分页和筛选。
- [ ] 敏感输入输出需脱敏。

# R3 模型服务真实路由与治理

## FR-R3-01 模型配置结构化

后端：

- 为模型服务增加结构化字段或强 schema：
  - 模型类别
  - 提供商
  - 模型名称
  - API 地址
  - 认证方式
  - API Key 密文
  - 默认参数
  - 超时时间
  - 重试策略
  - 状态
- API Key 必须加密存储。
- 响应只返回掩码。
- 编辑时提交掩码占位值不得覆盖真实密钥。
- 支持按提供商适配请求体和响应解析。

前端：

- 新增模型表单：
  - 类别
  - 提供商
  - 模型名
  - API 地址
  - API Key
  - 超时
  - 参数
- API Key 输入框默认空，不回显完整密钥。
- 保存后仅显示掩码。

验收标准：

- [ ] 数据库不保存明文 API Key。
- [ ] 前端不回显完整密钥。
- [ ] 掩码值不会被误保存。
- [ ] 模型配置可用于真实调用。

## FR-R3-02 模型连接测试

后端：

- 测试连接必须执行提供商要求的健康检查或最小模型请求。
- 记录：
  - 状态
  - 延迟
  - 错误分类
  - 测试时间
- 错误信息不暴露 API Key、内部地址、堆栈。

前端：

- 列表展示连接状态、最近测试时间。
- 测试中按钮禁用。
- 展示可理解错误。

验收标准：

- [ ] 可用/不可用状态来自真实请求。
- [ ] 测试失败不泄露密钥。
- [ ] 测试结果持久化。

## FR-R3-03 模型运行时路由

后端：

- 建立模型路由服务：
  - 按智能体 `modelId` 调用
  - 按现有模型档位调用
  - 失败降级策略
  - 超时和重试
- 记录路由决策和调用指标。

验收标准：

- [ ] 智能体模型配置优先生效。
- [ ] 模型不可用行为符合策略。
- [ ] 用量和费用统计可追踪。

# R4 安全防护运行时

## FR-R4-01 安全防护结构化配置

后端：

- 增加安全防护专用表或强 schema：
  - 名称
  - 描述
  - 过滤主题
  - 匹配方式：关键词 / 正则 / 分类模型
  - 命中等级
  - 阻止消息
  - 是否记录命中
  - 状态
- 支持配置校验，例如正则合法性。

前端：

- 提供专用表单。
- 支持主题标签管理。
- 支持阻止消息编辑。
- 支持状态启用/禁用。
- 危险操作二次确认。

验收标准：

- [ ] 不再依赖普通用户手工编辑核心 JSON。
- [ ] 配置错误可定位到具体字段。

## FR-R4-02 会话前安全拦截

后端：

- 在模型调用前执行安全防护。
- 支持多条策略按优先级执行。
- 命中后：
  - 返回阻止消息
  - 不调用模型
  - 写审计和命中日志
- 需防止提示词绕过。

前端：

- 展示明确阻止消息。
- 调试模式可看到命中策略摘要。
- 不默认展示用户敏感原文。

验收标准：

- [ ] 命中主题不会调用模型。
- [ ] 响应时间可接受。
- [ ] 命中有审计记录。

## FR-R4-03 安全策略测试

后端：

- 提供 `POST /platform/safety-guards/{id}/test`。
- 输入测试文本，返回命中策略、命中片段、拦截结果。

前端：

- 安全防护详情提供测试面板。
- 展示测试结果。
- 无后端能力时不显示假测试。

验收标准：

- [ ] 测试为真实执行。
- [ ] 命中片段可脱敏展示。
- [ ] 测试记录可选保存。

# R5 知识库运行时绑定

## FR-R5-01 配置态知识库与真实文档库打通

后端：

- 建立配置态知识库与现有文档/向量记录的归属关系。
- 文档上传必须指定知识库 ID。
- 向量检索必须支持知识库 ID 列表过滤。
- 删除知识库时明确数据保留、级联删除或禁用策略。
- 保留现有租户隔离。

前端：

- 上传入口可选择目标知识库。
- 文档列表按知识库过滤。
- 智能体绑定知识库时展示真实可用状态。

验收标准：

- [ ] 每个上传文档可归属知识库。
- [ ] 检索可按知识库过滤。
- [ ] 智能体只在绑定知识库内召回。

## FR-R5-02 知识库列表真实统计

后端：

- 返回：
  - 文件数
  - 解析中数
  - 失败数
  - 可用切片数
  - 存储大小
  - 更新时间

前端：

- 列表展示真实文件数和状态。
- 不展示虚构统计。

验收标准：

- [ ] 统计与文件列表一致。
- [ ] 无文件时显示 0。

## FR-R5-03 智能体知识召回摘要

后端：

- 返回每次智能体回答的知识引用。
- 引用包含来源、切片、分数、知识库 ID。
- 默认不暴露内部 embedding 或完整文档内容。

前端：

- 回答下方展示可点击引用。
- 调试区展示召回摘要。

验收标准：

- [ ] 仅绑定知识库内容可被召回。
- [ ] 引用可追溯来源。
- [ ] 调试模式可见召回分数摘要。

# R6 工作流可视化编排与执行

## R6.1 工作流数据模型

后端需定义稳定工作流 JSON 协议，至少包含：

- `version`
- `nodes`
- `edges`
- `variables`
- `inputSchema`
- `outputSchema`
- `executionConfirm`
- `layout`

节点字段建议：

- `id`
- `type`
- `name`
- `position`
- `parameters`
- `nextOnError`

边字段建议：

- `id`
- `source`
- `target`
- `condition`

要求：

- 兼容现有 `graph` JSON。
- 保存前校验：
  - 节点 ID 唯一
  - 边引用存在
  - 必填参数完整
  - 有入口节点
  - 无非法环
- 错误返回节点 ID 和字段路径。

## R6.2 前端画布需求

### FR-R6-01 节点面板

- 按类型分组展示节点。
- 支持搜索。

# R7 工具结构化配置与执行

## R7.1 API 工具

### FR-R7-01 表单式 API 工具配置

后端：

- 定义 API 工具 schema：
  - 请求方法
  - URL
  - 认证方式
  - Header schema
  - Query schema
  - Path 参数 schema
  - Body schema
  - 响应映射
  - 超时
  - 重试
  - 错误映射
- 凭据加密存储并脱敏返回。
- 保存前校验 schema。

前端：

- 提供分步表单：
  1. 基本信息
  2. 请求定义
  3. 参数 schema
  4. 响应映射
  5. 安全与超时
- 支持参数类型、必填、默认值、说明配置。

### FR-R7-02 代码式 API 工具配置

后端：

- 定义允许的语言和运行时。
- 代码必须运行在服务端沙箱。
- 限制：
  - CPU
  - 内存
  - 执行时间
  - 网络访问
  - 文件系统
  - 环境变量
- 代码变更需审计。
- 凭据通过受控注入，不允许写入代码明文。

前端：

- 提供代码编辑器。
- 提供输入输出 schema。
- 显示安全限制。
- 保存前做静态基础校验。
- 不在前端执行不可信代码。

### FR-R7-03 API 工具测试

后端：

- 提供 `POST /platform/tools/{id}/test`。
- 按参数 schema 校验输入。
- 执行真实请求。
- 返回状态、耗时、响应摘要、错误分类。
- 响应和错误必须脱敏。

前端：

- 根据 schema 动态生成参数表单。
- 测试中禁用提交。
- 展示状态码、耗时、响应摘要。
- 不展示完整敏感 Header。

## R7.2 SQL 工具

### FR-R7-04 SQL 工具配置

后端：

- SQL 工具必须绑定第三方数据库配置。
- 支持参数占位符。
- 保存前执行 SQL 安全校验：
  - 默认只允许 SELECT
  - 禁止多语句
  - 禁止危险语法
  - 限制返回行数
  - 限制超时
- 参数 schema 结构化存储。
- 数据库密码不回显。

前端：

- 数据库下拉选择。
- SQL 编辑器。
- 参数表格。
- 风险提示。
- 只读限制说明。

### FR-R7-05 SQL 工具测试

后端：

- 提供 SQL 工具测试接口。
- 使用只读连接或只读事务。
- 参数化执行。
- 返回列、行数、耗时、脱敏结果。
- 超时和最大行数限制。

前端：

- 动态参数表单。
- 结果表格。
- 错误信息。
- 大结果截断提示。

## R7.3 工具运行时调用

后端：

- 将工具 schema 转换为模型可理解的工具定义。
- 模型输出参数后按 schema 校验。

- 支持取消。
- 默认不展示完整原始响应。

验收标准：

# R12 安全与数据治理需求

## FR-R12-01 敏感字段密文存储

适用字段：

- 模型 API Key
- 数据库密码
- API 工具认证凭据
- 其他 token / secret

要求：

- 加密存储。
- 后端读取走受控解密。
- 列表和详情返回掩码。
- 编辑时掩码占位值不覆盖原值。
- 日志和错误不输出明文。

## FR-R12-02 脱敏展示

默认脱敏：

- API Key
- 数据库密码
- 认证 Header
- 完整内部堆栈
- 原始工具响应
- 完整内部推理
- 用户敏感输入
- 内部文件路径

管理员可查看的内容也需分级授权并审计。

## FR-R12-03 高危操作确认

必须二次确认：

- 删除智能体
- 删除工作流
- 删除知识库
- 删除文件和分段
- 删除模型
- 删除数据库
- 删除角色
- 禁用用户
- 上线/下线发布
- 执行 SQL 工具
- 代码式工具保存或执行

## FR-R12-04 审计与追踪

以下事件必须写审计：

- 登录 / 登出 / token 刷新
- 资源创建、修改、删除
- 发布、下线、回滚
- 权限和授权变更
- 用户启用/禁用
- 密钥配置变更
- 工具测试和执行
- SQL 执行
- 安全防护命中
- 智能体调用结果

审计需包含：

- 操作人
- 租户
- 资源类型和 ID
- 操作类型
- 时间
- 请求 ID / trace ID
- 结果状态
- 脱敏摘要

## FR-R12-05 限流与配额

智能体渠道、工具测试、SQL 测试、模型调用需具备：

- 用户级限流
- 租户级限流
- 超时控制
- 并发控制
- 费用配额检查
- 超限明确错误
