# 前端 UI 改造实施记录（P0/P1 第一阶段）

本次改造遵循《AI_Agent_Platform_UI_改造需求说明.md》，保持 Vue 3 + TypeScript + Element Plus + Vite 技术栈与既有 API、权限、租户逻辑，不引入新依赖。

## 已完成

### 基础框架

- 使用 `AppSidebar.vue` 替换原 64px 图标栏，建立分组式企业导航：
  - 工作空间：平台总览、智能体、工作流、工具管理、知识库
  - 平台配置：安全防护、模型服务、系统管理
  - 运营分析：对话工作台、评测中心、用量统计、管理员文档总览
- 保留浅色/深色主题，浅色为默认风格；品牌色继续沿用项目 teal 主色。
- 窄屏下侧栏收缩为图标模式；焦点态继续使用全局 `:focus-visible`。
- `WorkspaceHeader.vue` 按平台分区动态展示页面标题与说明，并为非聊天页提供角色、租户、个人设置入口。
- 现有聊天、评测、知识库、用量、管理员文档总览入口全部保留。

### 平台总览

新增 `PlatformOverview.vue`：

- 只使用 `/platform/*` 真实分页接口返回的 `total` 统计智能体、工作流、工具、知识库、安全防护、模型服务数量。
- 展示最近更新的真实智能体记录；无数据时显示明确空状态。
- 不生成虚构趋势图或指标。

### 智能体工作台

新增 `AgentStudio.vue`，桌面端三栏：

- 左栏：智能体真实列表、搜索、新建、选择。
- 中栏：配置导航 + 分区表单：
  - 基本信息
  - 模型与提示词
  - 工作流/工具/知识库/安全防护资源编排
  - 执行与对话设置
  - 高级 JSON
- 右栏：调试预览占位状态。当前配置资源尚未绑定到聊天执行接口，因此按钮禁用并明确说明“未接入运行时”，不模拟成功。
- 保存调用真实 `/platform/agents` 创建/更新接口；模型、工作流、工具、知识库、防护均来自真实列表接口。

### 工作流/工具/平台配置

- 工作流、工具、安全防护、模型服务、数据库继续通过兼容 JSON 数据模型的统一列表页管理。
- 保留搜索、分页、创建、编辑、删除、详情展开。
- 模型 API Key 等敏感字段由后端脱敏，前端不做明文回显。

## 当前边界 / 后续待做

- 工作流仍是 JSON 编辑，尚未实现拖拽画布、节点属性面板、自动布局、撤销/重做。
- 智能体调试尚未接入真实执行链路；需要后端提供“按智能体配置执行会话”的接口。
- 工具测试、安全防护策略测试尚无对应后端接口，前端未伪造测试结果。
- 系统管理当前仅包含第三方数据库配置；用户管理、角色管理需新增或暴露既有后端 API。
- 知识库入口仍复用现有文档上传/解析页面，配置态知识库与文件资源的深度详情页待后续整合。
