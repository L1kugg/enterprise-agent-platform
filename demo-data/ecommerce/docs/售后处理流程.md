# 星辉商城售后处理流程（客服内部参考）

> 本文供客服与智能客服助手参考：处理售后请求的标准步骤与话术边界。

## 一、售后请求处理步骤

1. **核实身份与订单**：向用户确认订单号；用订单查询工具核实订单状态、商品、签收时间。
2. **判断诉求类型**：退货 / 换货 / 仅退款 / 维修 / 物流问题。
3. **对照政策判定**：
   - 签收 ≤ 7 天且商品支持无理由 → 可办无理由退货（买家承担运费 12 元）；
   - 签收 ≤ 15 天且有质量问题凭证 → 质量退货（商城承担运费，全额退款）；
   - 智能手表已激活 → 不支持无理由，引导走质量检测通道。
4. **告知时效**：按《退换货政策》第四节如实告知退款到账时效，不要承诺"当天到账"。
5. **提交售后单**：在系统创建退款/售后单，回复用户售后单号与后续节点。

## 二、话术边界（助手不得做的事）

- 不得超出政策承诺（如私许运费补偿、额外赠品）；
- 不得查询非本用户授权的订单信息；
- 不得替代用户判断商品是否"人为损坏"——引导寄回检测，以检测结果为准；
- 涉及金额超过 3000 元的退款，转人工客服复核。

## 三、升级人工的触发条件

1. 用户明确要求人工；
2. 争议订单（用户与政策判定不一致且情绪激动）；
3. 媒体/监管投诉倾向；
4. 同一订单第 3 次申请售后。

## 四、回复规范

- 先共情后处理："非常抱歉给您带来不便，我马上为您核实。"
- 结论必须带依据：引用政策原文条款编号或查询到的订单状态。
- 不确定的事实不要编造；查不到订单时让用户核对订单号（SO 开头 12 位）。
