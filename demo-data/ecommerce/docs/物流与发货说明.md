# 星辉商城物流与发货说明

## 一、发货时效

| 订单类型 | 发货时效 |
| --- | --- |
| 现货商品（工作日 16:00 前下单） | 当天发货 |
| 现货商品（16:00 后下单） | 次日发货 |
| 预售商品 | 按商品页标注的预售结束后 48 小时内发货 |
| 法定节假日 | 顺延，大促期间（618/双11）最长不超过 72 小时 |

## 二、配送时效参考

- 华东 / 华北主要城市：顺丰 / 京东物流 **1-3 天**；
- 其他地区：**2-5 天**；
- 偏远地区（新疆、西藏、内蒙古部分区域）：**5-8 天**，部分大件商品不包邮。

## 三、物流查询

1. 订单发货后，物流单号实时同步，可在"订单详情 → 查看物流"查询轨迹。
2. 常见承运商：顺丰速运、京东物流、圆通速递。
3. 超过 48 小时物流无轨迹更新，可联系客服发起物流异常核查。

## 四、收货注意事项

1. 签收前请检查外包装是否完好，破损可当场拒收。
2. 大件家电（扫地机器人等）建议开箱验货后再签收。
3. 代签收视为本人签收，请提前告知代收人查验。

## 五、常见物流问题

- **显示已签收但未收到货**：可能是驿站代收或错投，请联系客服，24 小时内核实并补发或退款。
- **物流停滞**：运输途中超过 72 小时无更新，客服可发起催件或补发。
- **修改收货地址**：订单发货前可联系客服修改一次；发货后无法修改，可拒收后重新下单。
