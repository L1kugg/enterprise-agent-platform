# 星辉商城退换货政策

> 适用范围：星辉商城自营商品。第三方商家商品以商品详情页标注的售后政策为准。

## 一、七天无理由退货

1. 自商品签收之日起 **7 天内**（以物流签收时间为准），商品未使用、不影响二次销售的，可申请无理由退货。
2. 以下商品**不支持**七天无理由退货：
   - 贴身衣物、个人护理用品（已拆封）；
   - 已激活的智能穿戴设备（智能手表、手环）；
   - 定制类商品；
   - 已超过时效或赠品不齐的商品。
3. 退货商品须包含原包装、附件、赠品、发票；缺件将按比例扣除金额。

## 二、质量问题退货（15 天）

1. 自签收之日起 **15 天内**出现质量问题的（性能故障、做工缺陷、货不对板），可申请质量问题退货，**运费由商城承担**。
2. 质量问题退货不受"未使用"限制，但需提供照片或视频凭证。
3. 经检测确属质量问题的，全额退款（含原订单运费）。

## 三、换货政策

1. 自签收之日起 **15 天内**，支持同型号换货一次。
2. 质量问题换货运费由商城承担；个人原因换货运费由买家承担（每单 12 元）。
3. 换货商品自商城仓库发出后 1-3 天送达。

## 四、退款时效

| 退款类型 | 到账时效 |
| --- | --- |
| 未发货取消订单 | 审核通过后 **1-3 个工作日**原路退回 |
| 已退货退款（质量问题） | 商城收到退货后 **3-5 个工作日**原路退回 |
| 已退货退款（七天无理由） | 商城收到退货并验收合格后 **3-5 个工作日**退回 |
| 仅退款（未收到货） | 审核通过后 **1-3 个工作日** |

## 五、退货运费规则

1. 七天无理由退货：买家承担来回运费（每单 12 元）。
2. 质量问题退货：来回运费由商城承担，买家先行垫付后凭运费单据报销。
3. 商城发放的"运费券"可抵扣一次退货运费。
4. 退货地址以售后审批通过后系统提供的为准，请勿直接寄回仓库。
